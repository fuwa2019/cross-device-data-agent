## 决策与避坑验收

默认禁用正文解析，配置同时限定路径 glob、扩展名及字节上限。仅 JSON/TOML 安全解码与日志行限定键提取，不执行 YAML tag、脚本、pickle、checkpoint。只持久化 run_id 与有限路径引用，不保存全文和任意配置字段。缓存键包含元数据签名、策略与解析器版本。

目录角色候选与显式引用独立展示。重复 run ID、多配置、多权重、缺失结果、越界/失效引用保持歧义，不按 mtime 配对。POSIX no-follow dir_fd 逐级打开，正文读取前后比对签名。Windows 正文读取留待实测。

## 验证

`PYTHONPATH=src python3 -m unittest discover -s tests -v` 覆盖已知关联、歧义/缺失、重复 ID、禁读权重、未变化不重读、大小限制、坏 JSON、越界引用、替换为符号链接父目录。
