# M0 研究、决策与验证

查阅日期 2026-11-09。目标为最小 CLI 与离线目录工程骨架。

## GitHub 先行

- [gocatm](https://github.com/mtsagias/gocatm) README 明确 fork 自 [deadc0de6/gocatcli](https://github.com/deadc0de6/gocatcli)，沿链接核实上游。上游提交 `d8ae5514233dafb75d93cc5d57769a4e3daacbae`，API 显示最近推送 2026-11-07。已读 README、LICENSE、go.mod，GPL-3.0，Go 1.24 及 FUSE、TUI、压缩包等依赖。可直接用于通用离线目录，但本步需要扫描失败保留与来源交换语义。
- [Disk-Library](https://github.com/chka/Disk-Library) 提交 `851bab0137c86f9e7504e70c48834befc1ff55b4`。已读 README、MIT LICENSE、lib.py 的 `_walk_disk`、`audit_disk_sync`、staging/diff。实现以本地 SQLite 持久化，扫描异常存在 continue 路径，不能直接沿用为完整成功判据。README 所称同名同大小 exact duplicates 无法作为内容一致证据。本项目独立实现，未复制上游代码。

## 本步决策

采用 Python 标准库 argparse、sqlite3、tomllib，自研窄 CLI。复用系统 SQLite 和 Python 解析能力。省去平台与服务依赖，保持状态可导出。开源项目仅作为设计参考，许可证记录用于防止无意混入代码。

## 避坑验收

- 历史目录可被 Agent 独立调用 → 安装与 --help。
- 样本混入真实资料 → 生成器仅创建全新目标目录，内容全部合成。
- 需求历史包含个人路径 → 历史原始文档留本地，public 仓库仅发布实现和整理后的交付文档。

## 验证

见本步实际命令执行结果与后续 ACCEPTANCE。M0 骨架不声称扫描功能已实现。

最终交付复核再次验证 wheel 安装、--help、生成器与 README 命令。包无第三方运行依赖，构建依赖 setuptools>=77。
